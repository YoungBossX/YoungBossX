## 02 · FEATURED SYSTEMS

### 01. [AgentHub](https://github.com/YoungBossX/AgentHub)

**面向本机单用户开发的多 Agent 编程工作台。**

以 IM 交互组织任务拆解与角色协作，串联 **执行过程 → 真实 Diff → 审查结果 → 应用预览**，保留中断、重试和事件回放入口。

`FASTAPI / NEXT.JS` `MULTI-AGENT` `DIFF / REVIEW / PREVIEW`

<br/>

### 02. [XClaude](https://github.com/YoungBossX/XClaude)

**将工具执行、权限审批与会话恢复组织成可追踪的本地 Agent 运行时。**

通过独立的 x-core 常驻进程承载 Agent Loop，CLI 与 Textual TUI 作为客户端接入，集中管理工具调用、子 Agent 协作和执行记录。

`PYTHON / TEXTUAL` `AGENT RUNTIME` `SKILLS / MCP`

<br/>

### 03. [CC_Handmaking_LLM](https://github.com/YoungBossX/CC_Handmaking_LLM)

**围绕轻量语言模型开展 PyTorch 训练与评测实践。**

通过预训练、SFT、LoRA 与偏好对齐脚本，梳理从数据处理、模型训练到推理评测的链路，结合代码理解语言模型的关键机制。

`PYTORCH` `PRETRAIN / SFT` `ALIGNMENT`

## 06 · ENGINEERING PRINCIPLES

> **OBSERVABILITY**  
> 重要操作留下可查看的状态、日志与变更记录。

> **CONTROL**  
> 关键操作可介入，自动化过程可中断，执行边界保持明确。

> **LOCALITY**  
> 在适合的场景优先使用本地数据与执行环境。

> **SIMPLICITY**  
> 优先清晰的结构和可维护的实现，减少不必要的复杂度。

> **VERIFICATION**  
> 用测试与可检查的产物核对结果，区分已验证结论与待验证假设。
